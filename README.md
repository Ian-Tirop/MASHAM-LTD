# MASHAM-LTD Website

## Description
This is the sample, official website for Masham Limited, showcasing  projects, services, and core values.

## Technologies Used
- HTML
- CSS
- JavaScript
- FontAwesome

## Installation
1.Clone the repository and open the `index.html` file in your browser.

```bash
git clone https://github.com/yourusername/MASHAM-LTD.git
```

2. Open the project folder:
   
   ```bash
   cd MASHAM-LTD
   ```  
4. Open the `index.html` file in a browser to view the project.
